Часть A. Базовый Python
Что такое переменная?	Переменная – это объект с определенным именем, которому присваивается любое значение.
Зачем переменной давать имя?	Чтобы ее использовать в коде.
Чем текст отличается от числа?	Это другой формат данных (str / int (float))
Что такое логическое значение?	Это тип данных, который имеет только одно значение из двух: True или False
Для чего используется список?	Список используется для хранения информации, каких-либо значений (упорядочивает их)
Для чего используется словарь?	Для хранения данных и удобного поиска значения по заданным в словаре ключам
Зачем нужны условия?	Для того, чтобы проверить информацию на заданное соответствие 
Зачем нужны циклы?	Для повторения одной и той же операции
Что такое функция?	Это часть кода, обрабатывающая информацию, описанная отдельно для того, чтобы ее было удобно использовать повторно (вызывать)
Что может получить функция и что может вернуть?	Функция может получить новые данные (аргументы) и вернуть новое значение, новый результат

Часть B. Модули и библиотеки
Что такое модуль?	Это файл с кодом, который можно подключить к другому файлу
Что такое библиотека?	Библиотека — это набор модулей и функций, собранных для одной цели
Зачем проекту нужны библиотеки?	Библиотеки дают готовые инструменты для решения популярных задач
Что означает импортировать библиотеку?	Подключить ее в проект
Почему нельзя сказать, что любая библиотека уже является частью Python?	Его частью является только стандартная библиотека, остальные надо подключать (pip install)
Что такое зависимость проекта?	Это библиотека, которая нужна проекту для работы
Почему важна версия библиотеки?	Разные версии могут работать по-разному и иметь разный набор функций 
Что может произойти при несовместимых версиях библиотек?	Ошибка, код не будет работать
Почему программисту выгодно использовать готовую библиотеку?	Это экономит время и уменьшает ошибки
Приведите два примера задач, которые разумно решать готовой библиотекой.	С математическими вычислениями поможет NumPy, Pandas – с таблицами, scikit-learn – для обучения моделей ИИ

Часть C. LLM-агент и инструменты
Что такое LLM-агент простыми словами?	Это нейросеть, но ограниченная определенной ролью (несет определенный функционал и заточена под конкретную задачу)
Что такое Tool?	Внешняя функция или программа, которую агент вызывает для конкретного действия
Зачем агенту нужны инструменты?	Чтобы у агента была возможность искать информацию и ее обрабатывать, то есть взаимодействовать с внешними источниками
Кто принимает решение о необходимости вызвать Tool?	Решение принимает LLM на основе задачи и доступных инструментов 
Кто реально выполняет действие Tool?	Код программный
Зачем Tool нужны входные параметры?	Чтобы была поставлена конкретная задача
Зачем Tool нужен результат выполнения?	Результат нужен агенту, чтобы понять, достиг ли он цели, и что делать дальше
Зачем описывать ошибки инструмента?	Это помогает агенту понять, что пошло не так, и исправить + учесть это в будущем
Почему Tool должен иметь ограниченные права?	Для безопасности (чтобы инструмент не вмешивался в настройки системы или не менял те данные, которые должны быть сохранны в первоначальном виде)
Назовите пять возможных Tool для агента.	
1. Поиск в интернете 
2. Калькулятор 
3. Отправка email
4. Чтение/запись файлов 
5. Запрос к базе данных
